# backupx

**backupx** — менеджер бэкапов, написанный на языке **Vala** с использованием библиотеки **GTK 3**. Программа ориентирована на работу в окружении **MATE** и других GTK-системах.

### Функционал
* **Создание и проверка**: создание `.tar`-архивов с вычислением SHA-256 и управлением списком резервных копий.
* **Настройки**: управление путями и пресетами.
* **Диск**: отображение свободного места.

### Зависимости
Для работы программы требуются следующие системные компоненты:

| Компонент | Пакет в APT |
| :--- | :--- |
| **GTK+ 3** | `libgtk-3-0t64` (или `libgtk-3-0`) |
| **GLib 2.0** | `libglib2.0-0t64` |

**Команда для быстрой установки:**
```bash
sudo apt update && sudo apt install libgtk-3-0t64 libglib2.0-0t64
```
